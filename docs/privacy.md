# Privacy Handling

The original debugging process involved phone screenshots and local network details. For public sharing, this repository uses sanitized reconstructions only.

## Not Published

- Wi-Fi QR codes
- full MAC addresses
- Wi-Fi passwords
- precise device identifiers
- account names beyond the public author identity
- private screenshots

## Published Safely

- private LAN IP examples
- generalized app categories
- sanitized diagrams
- reusable debugging process
